Привет! Я Сергей — HTML-верстальщик и frontend-разработчик.

Более 5 лет занимаюсь коммерческой вёрсткой сайтов. Превращаю макеты Figma в адаптивные веб-страницы, создаю интерфейсы с помощью HTML, CSS и JavaScript, дорабатываю существующий код с учётом требований заказчиков.

Мне интересно не только точно воспроизводить дизайн, но и реализовывать интерактивность, продумывать поведение интерфейса на разных устройствах и делать страницы удобными для пользователей.

Сейчас углубляю знания JavaScript и развиваюсь в направлении React. В учебных проектах работаю с компонентами, хуками и данными из внешних API.

На сайте собрал примеры коммерческой вёрстки, учебные приложения и проекты с интерактивными интерфейсами.

Основные технологии: HTML5, CSS3, JavaScript ES6+, React, Git.
